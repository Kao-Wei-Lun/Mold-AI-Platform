# 射出成型短射 Demo 排查指南

本文件只用於 Mold AI Platform 公開合成 Demo。內容是工程排查順序與安全邊界，不代表特定模具、材料或機台的已證實根因，也不能直接形成機台設定指令。

## 現象確認

射出成型短射是熔膠未完整充填模穴而造成產品局部缺料。開始調整製程前，工程師應先確認缺料位置、發生比例、模穴別、材料批次與目前核准製程視窗，並排除量測或取樣錯誤。

## 建議排查順序

先檢查供料、材料乾燥狀態及料溫是否符合已核准規格，再檢查噴嘴、澆口與流道是否有冷料或阻塞。若短射集中在流動末端，應檢查排氣、肉厚突變、澆口位置與流動距離，不能只依單次試模結果宣告根因。

## 受控試模原則

製程參數只能在工程師核准的製程視窗內逐項調整。射壓、射速、熔膠溫度或模具溫度的候選變更，必須記錄調整前後數值、材料與機台相容性、觀察結果及停止條件。若出現毛邊、燒焦、噴射紋、壓力警報或超過設備與模具核准上限，應立即停止該候選步驟並交由工程師審查。

## 證據使用限制

歷史試模案例只能提供相似情境與候選排查方向，不能證明因果關係。缺少材料牌號、機台、模具版本或目前參數時，系統應回報資訊不足，不得自行帶入 Demo 預設值，也不得自動寫入 MES、PLC 或射出機。
